# Sticks — этикетки и маркировка (PWA)

Печать этикеток для кухни и склада: телефон, планшет, ПК. Офлайн, установка как приложение.

**Запуск на GitHub Pages:** залить содержимое в ветку `main` → Settings → Pages → Source: *GitHub Actions* (workflow уже в `.github/workflows/pages.yml`).

**Офлайн-библиотеки:** при первом заходе сервис-воркер кэширует QR и Excel с CDN. Для полной автономности положите `qrcode.min.js` и `xlsx.full.min.js` в папку `vendor/` — приложение возьмёт их первыми.

## Что исправлено относительно старой версии
- QR: вызов `addData(text,'H')` передавал уровень коррекции вместо режима — теперь режим `Byte` + UTF-8, кириллица читается.
- `sw.js` кэшировал несуществующие файлы (`parser.js`, `map.js`, `modules/*`) — установка воркера падала, офлайн не работал.
- Абсолютные пути (`/`, `/assets/icons/...`) ломались на `username.github.io/sticks/`; иконок не было вовсе. Теперь пути относительные, иконки созданы.
- Названия вставлялись через `innerHTML` без экранирования (XSS) — теперь экранируются.
- Срок годности считался `setHours` (ошибки при смене времени) — теперь точные часы.
- Данные в `localStorage` без лимита — теперь IndexedDB; старые данные (`nls_*`) переносятся автоматически.
- Импорт Excel пересоздавал весь список с одинаковыми `id` — теперь объединяет по названию.
- «Сброс» делал `localStorage.clear()` для всего домена — теперь чистит только данные Sticks.
- Убраны мёртвые файлы: 5 старых версий `index*.html`, недоделанные `js/*`, Electron, workflows для npm/Jekyll.

## Структура
`index.html` · `css/app.css` · `js/app.js` · `sw.js` · `manifest.webmanifest` · `icons/`

## Универсальность
Программа не привязана к компании: название задаётся в «Настройки → Печать», внешний вид этикетки — во вкладке «Макет» (блоки, размеры, логотип, перетаскивание). Фон приложения — пресеты или своё фото.

## Конструктор макетов («Макет»)
Свободное расположение элементов в мм: текст, поле «подпись + значение», QR, линия, рамка, логотип, фон-картинка.
Перетаскивание и размер пальцем/мышью с подсказками-линиями, кнопки выравнивания по горизонтали и вертикали, ввод текста прямо на этикетке (повторное нажатие), переменные `{name} {open} {exp} {temp} {by} {batch} {al} {co}`, отмена/возврат, слои, дубликаты, масштаб, сетка, тестовая печать, экспорт/импорт макета файлом, проверка орфографии (LanguageTool онлайн; без сети — базовые правила).
Горячие клавиши на ПК: стрелки — сдвиг (Shift — крупнее), Delete, Ctrl+Z / Ctrl+Y, Ctrl+D, Enter — править текст.

## Инструменты (вкладка «Инструменты»)
Сроки (контроль напечатанных позиций по времени до истечения), таймеры (сохраняются при перезапуске), калькулятор срока годности, конвертер единиц (масса, объём, температура), печать пустых бланков для ручного заполнения.

## Настройки (поиск по ним сверху)
Внешний вид (темы, акцент, фон, размер, скругление, плотность, контраст, эффекты) · управление и звук (вибрация и её сила, звуки, подтверждение удаления, экран) · печать (компания, макет, режим, копии, формат даты, срок до конца суток) · подстройка принтера (масштаб, сдвиг X/Y, зазор и поля A4, рамка) · сроки и статусы · сотрудники · пресеты · данные и хранилище (защита от очистки, резервная копия, импорт/экспорт Excel) · приложение (установка, очистка кэша).
